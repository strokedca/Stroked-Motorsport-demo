1. Extract All from this package.
2. Run RUN-PASSWORD-UPDATE.cmd.
3. The script generates a NEW password locally and copies it to the clipboard. At EACH of the next THREE age prompts, press Ctrl+V then Enter. Typing is hidden.
4. A message then asks you to update the backup-recovery password for stroked.ca in Edge Password Manager. Paste the new password, SAVE it, hide the field, and close that password panel. Click Yes in the script message only after saving it.
5. Leave the final result open; share only that result with the password pane closed.

The underlying age key stays the same. The script tests both existing archives before updating the protected key in OneDrive. Previous encrypted wrappers are kept privately for rollback; older downloaded ZIPs and OneDrive history may still contain the old password wrapper. Cloud upload and the full database restore drill remain separate checks.
